# Lighting

## Lightning

Strikes lightning at random positions near target, with optional extra damage.

```yaml
type: lightning
count: 2
radius: 3
damage: 4
```

Default `target: TARGET`.

#### Field Details

**count**

Number of lightning strikes.

```yaml
count: 5
```

**radius**

Random radius around target.

```yaml
radius: 6
```

**damage**

Additional damage dealt to hit entities.

```yaml
damage: 8
```
