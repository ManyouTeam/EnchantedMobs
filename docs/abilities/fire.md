# Fire

## Fire

Sets target on fire.

```yaml
type: fire
fire-ticks: 60
accumulate: true
```

Default `target: TARGET`.

#### Field Details

**fire-ticks**: burn duration in ticks.

```yaml
fire-ticks: 100
```

**accumulate:** accumulate the freeze ticks. (Added in 1.2.0)

```yaml
accumulate: true
```
