# Arrow Rain

## Arrow Rain

Spawns arrow rain above target area.

```yaml
type: arrow_rain
count: 10
radius: 4
height: 12
spread: 0.18
damage: -1
pierce-level: 0
critical: false
```

Default `target: TARGET`.

#### Field Details

**count**: number of arrows.

```yaml
count: 20
```

**radius**: rain area radius.

```yaml
radius: 6
```

**height**: spawn height.

```yaml
height: 16
```

**spread**: initial random velocity spread.

```yaml
spread: 0.3
```

**damage**: arrow damage; `< 0` keeps default damage.

```yaml
damage: 5
```

**pierce-level**: piercing level.

```yaml
pierce-level: 2
```

**critical**: whether arrows are critical.

```yaml
critical: true
```
