# Freeze

## Freeze

Sets freeze ticks (powder-snow freezing behavior).

```yaml
type: freeze
freeze-ticks: 60
accumulate: true
```

Default `target: TARGET`.

#### Field Details

**freeze-ticks**: freeze duration in ticks.

```yaml
freeze-ticks: 120
```

**accumulate:** accumulate the freeze ticks. (Added in 1.2.0)

```yaml
accumulate: true
```
