# Shuffle Inventory

## Shuffle Inventory

Randomly shuffles items in player inventory slot range.

```yaml
type: shuffle_inventory
start-slot: 0
end-slot: 35
```

Default `target: TARGET`.

#### Field Details

**start-slot**: start slot (inclusive).

```yaml
start-slot: 9
```

**end-slot**: end slot (inclusive).

```yaml
end-slot: 35
```
